## Built for the algorithm

- **1-second hook.** An impossible claim, *"an AI made this"*, in the first word, and frame 0 works as the cover.
- **Retention device.** A live countdown and progress rail in the HUD from 0:06.
- **A cut on every beat.** Visual change every 0.5–2 s; each scene uses a different technique, so there is never a static frame.
- **Local jokes that trigger comments.** *irkotta vs piżelli*, traffic = *kaos*, *il-fenek fit-tnejn*, the Maltese word *bank*.
- **Comment bait.** A binary question anyone can answer: *Irkotta jew piżelli?*
- **Loop.** The last frame types back into the first, which lifts rewatch rate and average watch time.
- **Series framing.** "EP. 01 · jiġi dalwaqt: EP. 02" gives viewers a reason to follow.
- **Safe zones.** Critical text stays inside x 72–1008 and y 300–1480 (clear of TikTok and Reels UI).
- **Sound-off friendly.** Every idea is carried by on-screen Maltese text; the sound design is a bonus.
