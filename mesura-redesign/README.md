# Mesura homepage redesign

Three working homepage prototypes for [Mesura](https://mesura.ai), the free AI readiness survey for Malta.

Open `index.html` for the overview, or go straight to a route:

| Route | File | Idea |
| --- | --- | --- |
| A · Datum | `datum.html` | A surveyor's benchmark. A live survey map of the Maltese Islands, and a report plotted like a levelling line. Light and dark themes. |
| B · Madum | `madum.html` | Six scores draw a Maltese cement tile. Drag a score to redraw it. |
| C · Six | `six.html` | Dark and product-led. Three questions sketch your readiness hexagon, then a scroll story builds the report. |

Plain HTML, CSS and JavaScript: no build step and no dependencies beyond web fonts. `shots/` holds the screenshots used by the overview.

Sample scores and benchmarks are illustrative. Real data: Eurostat news release, 16 December 2025. Coastline © OpenStreetMap contributors (ODbL), via geo-maps.
